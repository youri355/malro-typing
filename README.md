# 말로 타이핑

키보드 대신 말로 글을 쓰는 Windows 프로그램입니다. 카카오톡·메모장·인터넷의 글 쓰는 칸에서 사용하세요. **메시지를 보내지는 않습니다.** 글을 확인한 뒤 전송은 직접 눌러 주세요.

만든 사람 겨울작가 · [theaiwk.com](https://theaiwk.com)

**위 링크를 누르면 설치 파일 하나를 바로 받습니다.** 깃허브 회원가입은 필요 없습니다.

받을 파일 이름: **MalroTyping_Setup_1.1.6.exe**

### 2. [그림을 보며 따라 하는 사용 안내서 열기 (구글 문서)](https://docs.google.com/document/d/10uYQpzBxtleMlSZvZWsCxAr6gIwLgJS9XlHalg3fnOE/edit?usp=sharing)

설치 파일 찾기부터 처음 설정, 메모장에서 첫 문장 쓰기, 카톡에서 사용하기, 단축키 바꾸기, 문제 해결까지 화면 캡처와 함께 설명했습니다. 링크를 누르면 읽을 수 있으며, 수정 권한을 신청할 필요는 없습니다.

## 설치하기

1. 위 **설치 파일 받기**를 누릅니다.
2. 받은 **MalroTyping_Setup_1.1.6.exe**를 빠르게 두 번 누릅니다. 파일을 못 찾으면 파일 탐색기의 **다운로드** 폴더를 확인하세요. .exe가 안 보이는 PC에서는 종류가 **응용 프로그램**인 파일을 고르면 됩니다.
3. 설치 화면의 안내를 따라 마칩니다. **압축을 풀거나 별도 명령어를 입력할 필요가 없습니다.**
4. 말로 타이핑의 처음 설정 창이 열리면, 잘 모르겠을 때는 기본값 그대로 **저장**을 누르세요.
5. 처음 한 번 음성 인식 파일을 받습니다. **‘준비됐어요’가 나올 때까지 기다린 뒤** 사용합니다.

**설치 경고가 나오면:** 공식 링크에서 받은 파일인지 먼저 확인하세요. Windows의 ‘PC 보호’ 안내는 [추가 정보]에서 내용을 확인하고 실행 여부를 결정합니다. 출처가 다르거나 백신이 구체적인 위협을 알리면 멈추고 문의하세요. 백신을 끄거나 회사 PC의 보안 설정을 우회하지 마세요.

## 처음 한 문장 써 보기

1. 메모장을 열고 **글 쓸 빈 공간**을 누릅니다.
2. **Ctrl과 Alt를 누른 채 F9를 한 번 누르고 손을 뗍니다.** ‘띵-딩’ 소리가 나면 말하세요.
3. 다 말했으면 **같은 키를 한 번 더** 누릅니다. ‘똑-딱’ 소리가 나면 녹음이 끝납니다.
4. 글이 들어올 때까지 기다린 뒤 틀린 곳을 고칩니다. 카톡에서는 상대방과 내용을 확인하고 **Enter·전송을 직접** 누르세요.

기본은 **말을 끝낸 뒤 한꺼번에 입력**합니다. NVIDIA 그래픽카드가 감지된 PC는 설정에서 **말하는 동안 따라 입력**을 고르지만, 이 방식도 지연이 있습니다. 키가 불편하면 [설정]에서 F8 하나 또는 왼쪽 Ctrl 두 번 등으로 바꾸세요.

창을 치우고 계속 쓰려면 **창 숨기기**를 누릅니다. **X는 종료**이므로 구분해 주세요. 빨간 마이크 아이콘은 녹음 중입니다. 유튜브 등 다른 소리가 들어가지 않도록 말을 마치면 녹음도 끝내세요.

## 이미 쓰고 계신 분: 새 버전으로 바꾸기

녹음을 끝내고 남은 글을 먼저 확인한 뒤, 앱의 **새 버전 … 업데이트** 버튼을 누르세요. 설치 창이 보인 뒤 다시 켜지며 설정·단어 사전은 유지합니다.

1.1.3 이하이거나 보안 프로그램 때문에 업데이트가 막힌 경우에는 위 최신 설치 파일을 직접 받아 설치하세요. 업데이트와 문제 해결은 [그림 안내서](https://docs.google.com/document/d/10uYQpzBxtleMlSZvZWsCxAr6gIwLgJS9XlHalg3fnOE/edit?usp=sharing)에 정리했습니다.

## 사용 조건과 개인정보

- **Windows 10·11, 64비트 PC와 마이크**가 필요합니다. 맥·휴대폰용 설치 파일이 아닙니다.
- 처음 설정 때 인터넷으로 ‘정확하게’ 모델 약 **1.6GB**를 받으며, NVIDIA 가속을 쓰면 약 **1.2GB**를 더 받습니다. ‘가볍게’ 모델은 약 0.5GB지만 오타가 더 많습니다.
- 음성을 글로 바꾸는 작업은 **내 PC 안에서** 합니다. 음성과 인식한 글을 외부 음성 인식 서버로 보내지 않습니다.
- 하루 한 번 새 버전 정보를 확인하고, 업데이트할 때 설치 파일을 받습니다. 버전 알림은 설정에서 끌 수 있습니다.

이 저장소는 설치 파일 배포용입니다. 프로그램 소스는 비공개입니다.
