# 말로 타이핑

말한 내용을 클릭한 입력칸(카톡·메모장·브라우저 등)에 글로 넣어 주는 Windows 음성 입력 프로그램입니다. 만든 사람 겨울작가 · https://theaiwk.com

- 음성은 내 PC 안에서만 글로 바뀌고, 음성·글·개인 정보는 어디에도 보내지 않습니다.
- 1.1.2부터 하루 한 번 이 저장소의 **최신 버전 번호만** 확인해, 새 버전이 있으면 알려 주고 버튼 하나로 업데이트합니다(설정에서 끌 수 있음).

## 받기

[Releases](https://github.com/youri355/malro-typing/releases/latest)에서 `말로타이핑_설치_<버전>.exe`와 사용 안내 PDF를 받으세요.
설치 중 파란 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.

이 저장소에는 설치 파일만 올립니다. (프로그램 소스는 비공개)
